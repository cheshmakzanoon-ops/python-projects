# Provenance and licensing

All equipment observations, labels, drift fixtures and benchmark inputs are generated by this project's original `data_contracts/schema.py` implementation. No external dataset, pretrained model, asset, icon, audio or copied code is redistributed.

The repository owner has not selected a source-code license. Recommendation: choose MIT or Apache-2.0 after reviewing the intended distribution and dependency notices. No license identifier or claim of permission is invented here; dependency licenses do not supply a license for authored source.

Runtime libraries are resolved exactly by `uv.lock`: NumPy (BSD-3-Clause), scikit-learn (BSD-3-Clause), PyArrow / Apache Arrow (Apache-2.0), FastAPI (MIT), Pydantic (MIT), uvicorn (BSD-3-Clause), skops (BSD-3-Clause), with their transitive dependencies and their own notices. Build/test tooling includes Hatchling, pytest, Hypothesis, Ruff, mypy and httpx. Consult each installed distribution's metadata and bundled license notices for the exact resolved releases, including transitive numerical runtimes. Do not relicense dependency code under the portfolio's eventual source license.

Methodological references, used as design guidance rather than copied implementation:

- [scikit-learn common pitfalls](https://scikit-learn.org/stable/common_pitfalls.html): train-only preprocessing and leakage.
- [scikit-learn model persistence](https://scikit-learn.org/stable/model_persistence.html): trust, supported formats and version compatibility.
- [skops persistence](https://skops.readthedocs.io/en/stable/persistence.html): inspecting untrusted type names and explicit trust review.
- [SQLite atomic commit](https://sqlite.org/atomiccommit.html): durability boundaries and filesystem assumptions.

PR-AUC in reports is sklearn average precision, not a trapezoidal interpolation claim. PSI uses training quantile bins, epsilon-smoothed empty bins and descriptive comparisons; it is not an accuracy test.
