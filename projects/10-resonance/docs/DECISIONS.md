# Decisions

* Fixed overlap YIN rather than shrinking autocorrelation: all lags compare the same number of samples, avoiding lag-dependent bias. FFT correlation replaces only the dot-product kernel; an explicit direct-sum oracle checks its indexing.
* Energetic stereo channel rather than a stereo mean: anti-phase mono content would disappear on averaging. The array API chooses globally with left tie-break; file streaming chooses once from its first second and retains that channel. It does not separate instruments; alternate-channel quality is outside this policy.
* Silence abstention rather than guessed notes: RMS <.003 or insufficient periodicity is unvoiced. RE-01 counts every abstention as failure, so the clean-grid score cannot improve by selective omission.
* Integer sample authority rather than accumulated floating seconds: randomized chunks give identical timestamps, frames and estimates; output time conversion occurs only for presentation/MIDI.
* Edit alignment preserves insertion and omission without forcing distant pitches into reference matches. Traceback needs one byte per cell and only two cost rows; retaining all floating scores adds memory without helping reconstruction. The checked 4,000,000-cell default remains a time/memory guard. Banded/checkpointed alignment would change the complexity further but needs a stated band policy and independent correctness evidence.
* Offline note segmentation rather than a pretrained transcription model: this exposes uncertainty and failure semantics; universal polyphonic transcription is excluded.
* Source digests rather than a bare Git hash: development evidence honestly identifies dirty snapshots. Final evidence must be regenerated on an immutable committed snapshot.

* Repeated-pitch articulation needs onset evidence: a sustained pitch trajectory alone cannot distinguish two adjacent same-pitch attacks. Credible attacks split events, while smooth bend/vibrato trajectories remain one event absent a new attack.
* Reject sub-tick MIDI events: rounding can collapse a valid sample interval to one tick position, making note ordering impossible. Raising a clear error before writing preserves both MIDI validity and an existing output file. Explicit positive tempos are checked independently instead of assuming the default tempo.

* Framing is an owned iterator protocol. Accepting a feed copies samples immediately, and state advances before a frame is returned. A partial batch must be closed before another feed; an interrupted flush may resume only without new samples. This prevents caller mutation, interleaved iteration and suspended generators from changing previously accepted audio or replaying timestamps. Pending samples remain visible resource ownership rather than being silently discarded.
* Adaptive onset thresholds have a finite temporal horizon. A recording-global peak made an earlier quiet attack depend on an unrelated future loud attack. Both relative-peak and median floors now use ±8 frames. A three-frame energy envelope suppresses periodic RMS ripple that would otherwise masquerade as new attacks after removing that global suppression.
* One attack credibility rule governs all decoder decisions. Confidence below .5 cannot split an event, snap its start or support a pitch reattack. A sorted event index avoids repeated whole-trajectory scans for nearest attacks.
* Dimensionless periodicity requires scale-independent normalization. An absolute `1e-20` energy cutoff made tiny but explicitly above-threshold waveforms aperiodic. Dividing every positive cumulative energy preserves the algebraic ratio; exactly zero energy remains an abstention. This does not change the default PCM silence threshold.
* Evaluation owns its denominator. Recording length and frame configuration are required inputs to challenge trajectory scoring; returned records cannot define the population being evaluated. Missing outputs are misses, ambiguous timestamps are errors, and undefined conditional errors are null. Original evidence remains evidence for its recorded evaluator.
* Playback provenance identifies encoded bytes separately from source audio. A re-encoded mono prefix cannot share the original stereo recording's byte hash. Rendering verifies samples/rate before plotting and returns clip provenance for both HTML and JSON. This prevents a visually plausible figure from being paired accidentally with different playback.
