# Provenance and license status

All default audio, note annotations, score examples, figures and MIDI are generated by this project's authored deterministic signal generator. No external audio sample, pretrained model, hosted transcription, copied implementation, icon pack or dataset is distributed. Generated audio is synthetic and is never represented as a human performance.

The YIN method is described in de Cheveigné and Kawahara, JASA 111, 1917–1930 (2002), DOI 10.1121/1.1458024. This code is an independent implementation from the algorithm description, not a copied source excerpt. SciPy's explicit-window STFT supplies the independent transform comparison. Numerical tolerances and deliberate policies are documented in FIXTURES and ARCHITECTURE.

Direct libraries: NumPy (BSD-3-Clause numerical kernels), SciPy (BSD-3-Clause independent references), SoundFile (BSD-3-Clause Python interface; underlying libsndfile LGPL-2.1-or-later), Matplotlib (PSF-based license scientific figures), mido (MIT MIDI serialization). Dev tools include pytest (MIT), Hypothesis (MPL-2.0), mypy (MIT), Ruff (MIT), coverage/pytest-cov (Apache-2.0/MIT), and hatchling (MIT). Exact package versions and artifact hashes are locked in uv.lock; installed distributions retain their own notices. Dependencies are not vendored here.

The repository has no owner-selected code license at implementation time. This project does not claim an SPDX code license or imply broad redistribution permission for repository code. Recommendation to the owner: choose an explicit permissive license such as MIT or Apache-2.0 after reviewing ownership. This is not public package publication authorization.
