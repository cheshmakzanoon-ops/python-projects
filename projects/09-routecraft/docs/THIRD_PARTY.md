# Provenance

All island coordinates, directed matrices, tiny fixtures, route algorithms and
test data are original synthetic material generated by this package. No road
network, customer data, external dataset, copied optimization code, pretrained
model or proprietary service is included. SVG reports are rendered from actual
verified run data.

Matplotlib (PSF-based Matplotlib license) renders charts; its locked dependencies
include NumPy (BSD-3-Clause), Pillow (HPND), contourpy (BSD-3-Clause), cycler
(BSD-3-Clause), fonttools (MIT), kiwisolver (BSD-3-Clause), packaging
(BSD-2-Clause/Apache-2.0), pyparsing (MIT), python-dateutil (Apache-2.0/BSD-3-Clause)
and six (MIT). Dependency packages retain their own bundled license notices;
`uv.lock` records exact distributions. These libraries do not supply the routing
solver. Development dependencies include pytest, Hypothesis, mypy, Ruff,
pytest-cov and Hatchling; consult their installed metadata for full notices.

The repository owner has not chosen a license for original code. MIT is a
reasonable recommendation for an educational portfolio, but no license choice or
redistribution grant is invented here. This does not prevent local development
and verification. No registry publication is performed.
