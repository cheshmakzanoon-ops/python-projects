# Shared change requests

None. Strata follows the independent uv project and shared CLI contracts and
requires no network service, port, credential, or sibling implementation.

Required platform: Linux / local POSIX filesystem for lock and fault semantics.
Required Python versions: 3.13.16 and 3.14.8. The default is selected after both
full suites pass. Final standard benchmarks must run under the coordinator's
exclusive resource lease from an immutable committed source snapshot.
