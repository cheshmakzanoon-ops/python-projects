# Provenance and license

All default dataset rows are generated by Anchor (`id`, `id²`) and contain no third-party
assets. The ZIP and CSV demo outputs are original generated fixtures. No model, audio,
private dataset, copied implementation or paid API is used.

Runtime dependencies are psycopg (PostgreSQL driver and pool), FastAPI/Pydantic (HTTP
validation), Typer/Click (CLI), and uvicorn (local ASGI serving). Resolved versions and
transitive dependencies are in `uv.lock`; dependencies retain their upstream licenses.
Development dependencies are pytest/coverage, Hypothesis, Ruff and mypy. Package metadata
makes no invented license declaration; the repository owner has not selected a code
license. Recommendation: choose an explicit permissive license before redistribution.

Conceptual references: PostgreSQL SELECT/locking documentation for SKIP LOCKED queue
semantics, and Temporal's workflow-definition documentation for deterministic command
replay and external activities. Anchor implements its own deliberately bounded model.
