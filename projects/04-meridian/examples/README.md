# Equipment-rental scenario

Run the CLI demo with an absolute external output directory. It creates all synthetic identities in an owned database schema; no account IDs in source need editing. The generated demo.json contains the resulting immutable journal/sequence identities, duplicate-request equality, reversal target, ambiguous match review, and independent audit/rebuild outcome. report.html renders that same evidence without JavaScript or external assets.

An example request body is in journal-request.json; replace the obvious account placeholders with accounts created for your own verified tenant. Amounts are decimal strings; JSON floats are rejected.
