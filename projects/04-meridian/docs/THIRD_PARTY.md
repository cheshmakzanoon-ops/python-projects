# Provenance

All default invoices, payments, statements, tenants, and references are generated fictional fixtures authored in this project. No external financial data, copied code, models, icons, or paid service assets are redistributed. The matching solver and accounting/allocation/replay logic are original Python implementations.

Runtime dependencies: Django (BSD-3-Clause), psycopg/psycopg-binary (LGPL-3.0 with applicable linking exceptions; inspect installed distributions for full notices). Development dependencies include pytest (MIT), pytest-django (BSD-3-Clause), Hypothesis (MPL-2.0), django-stubs (MIT), Ruff (MIT), mypy (MIT), Hatchling (MIT), coverage tooling (Apache-2.0). Exact versions and transitive packages are resolved in uv.lock; installed package metadata is authoritative for full license text and exceptions.

PostgreSQL is supplied externally under the PostgreSQL License; it is not bundled in this wheel. Standard library modules are part of CPython under its distribution licenses. No application code license was preselected in the repository; the coordinator records that owner decision rather than inventing a license identifier.
