# Provenance and dependencies

All device readings, metadata strings, NDJSON fixtures and benchmark inputs are generated by this project's seeded code. No external dataset, model, image, audio, icon, or copied algorithm implementation is redistributed. Python's standard-library SQLite adapter uses the SQLite library available with CPython.

Runtime CLI parsing uses Typer and its locked transitive packages; package builds use Hatchling. Development uses pytest, pytest-cov, Hypothesis, Ruff and mypy. Exact versions and artifact hashes are in uv.lock. Their upstream distribution metadata and notices govern their licenses; dependencies are installed from their distributions, not vendored here. In particular Hypothesis is MPL-2.0 licensed; no Hypothesis implementation is copied into this package.

The repository owner has not selected a code license. This project does not invent a license grant or public package publication status. The owner should choose an appropriate repository license before representing redistribution rights.
