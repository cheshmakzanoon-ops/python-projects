# Independent adversarial review

These reviews used separate reasoning and, where relevant, independently calculated outcomes. A passing review is bounded evidence, not proof of absence of defects. Project regression tests retain the fixes; final clean-commit reports identify the verified source.

| Product | Findings and independent checks |
| --- | --- |
| Anchor | Coordinator inspected reducer/replay, epoch fencing, cancellation/compensation and provider boundary. Settlement drives actual HTTP commit, process death, idempotent retry and reversal in separate package environments. |
| Strata | Reproduced descriptor leak when WAL constructor directory sync fails and acceptance of unsupported backup format. Both corrected with regressions. Independent checks covered MVCC, snapshots/compaction, corruption refusal, writer poisoning and recovery. |
| Current | Coordinator reviewed admission ordering, durable controls, watermark/late semantics, outbox revisions and independent raw-trace oracle. Stream-lake drives duplicate/old revision delivery and pinned historical reads. |
| Meridian | Reproduced cross-tenant cached idempotency and mutable account identity after statement-only/empty-run use. Composite relational constraints and locking now enforce the invariants. Re-review exercised four actual PostgreSQL lock-wait races, legacy bad-row upgrade refusal and 1,000 exhaustive small matching graphs, including very large integer costs. Fixed finite-distance sentinel collision; unmatched costs of 10^1000 remain exact. |
| Quarry | Coordinator reproduced unbounded aggregate CSV record handling and inspected source-consumption/mutation races. Bounded single-line CSV and consumed-byte fingerprint validation now enforce the contract. Reviewed historical version conflicts, tombstones, partition-local invalidation, GC and spill ownership. |
| PyTrace | Coordinator found full file reads preceding advertised limits. Source/cache/config/codemod and journal reads now check size and bound actual reads. Reviewed conservative alias/shadow behavior and explicit process-crash recovery limits. |
| Atlas | Coordinator audited all 60 authored relevance intents and pooled label semantics independently of scorer outputs; see [judgment review](atlas-judgment-review.md). Code-search verifies hidden-score invariance, restricted direct access, obsolete finding deletion and next-request revocation. |
| Proving Ground | Reproduced fractional Parquet IDs/labels silently truncating before hashing, duplicate default/override model arguments and NaN embargo comparisons. Exact Arrow schemas, validated parameters and finite/exact split fields now reject malformed input. Independent closure passed 58 checks, including null/duplicate/wrong-type columns, valid overrides and fractional/bool memberships. Positive review covered train-only transforms, report binding, promotion CAS, failed loads, rollback and interrupted artifacts. |
| Routecraft | Independent labeled-assignment/permutation enumeration matched exact objective/status on 180 directed cases (137 feasible, 43 infeasible). Heuristics returned 129 optima, four suboptimal plans and four honest misses. Another 24 independently calculated rolling cases checked delayed boundaries, cargo, directed costs and new jobs. Found unordered stop tuples accepted then crashing indexed solver; explicit canonical-order validation now returns INVALID_INPUT, and reviewer reran the reproduction. |
| Resonance | Independent NumPy synthesis, SciPy STFT reference, MIDI byte parser and mido checked numerical/event/export contracts. Reproduced merged same-pitch reattacks, zero-tick export and hardcoded checker tempo. Re-review confirmed two adjacent plucks split, continuous bend/vibrato stays one event, invalid export preserves preexisting bytes, tempo600000 timing is correct, and adjacent one-tick off/on ordering roundtrips. Fixed pitch denominator is all6,272 frames; no silent exclusions. |

Original implementation assignments ran in waves under the actual seven-slot limit (coordinator plus at most six workers). Completed owners reviewed sibling projects read-only; only the coordinator changed shared files or Git. All ten roles were retained. No claim is made that eleven agents ran simultaneously.

Root CI selection received a separate read-only review. It reproduced canonical path aliases referencing nine directories through ten identities, and a Git path with non-UTF-8 bytes escaping the conservative fallback. Directory uniqueness now uses resolved paths; undecodable diffs select all projects. Actual Git-path and alias regressions pass in the 13-test root suite. The reviewer also checked exit propagation, POSIX group cleanup, aggregate failure handling, pinned Actions and read-only permissions.
